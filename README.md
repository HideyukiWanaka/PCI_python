## README

### プロジェクト名

歩行分析ツール (仮称: GaitAnalysis_PCI_App_v1)

### 概要

このツールは、左右の下腿または足部に装着された IMU（慣性センサー：加速度計、角速度計）から記録された CSV 形式のデータを用いて、歩行パラメータを算出するための Python アプリケーションです。以下の主要な機能を備えています。

- **データ同期:** 開始時の衝撃信号に基づき、左右センサー間の時間的なズレを自動または半自動（パラメータ調整）で補正します。
- **歩行周期同定:** 同期された角速度データから、踵接地（IC）と爪先離地（FO）のタイミングを同定します。
- **トライアル抽出:** 記録全体から、指定された条件（IC 間の時間差、最小歩数）に基づいて歩行中のトライアル区間を自動的に分割・抽出し、さらに各トライアルの開始・終了部分を除外して定常歩行部分を特定します。
- **パラメータ算出:** 抽出された定常歩行データから、以下のパラメータを算出します。
  - 時間関連パラメータ（ケイデンス、ストライド/立脚/遊脚時間とその変動係数(CV)・割合）
  - 運動学的パラメータ（最大遊脚期角速度、ピーク立脚期角速度とその CV など）
  - 位相協調指数（PCI）および関連指標
  - 各種パラメータの左右対称性指数（SI）
- **結果の出力:** 算出された全パラメータを CSV ファイルに保存し、主要な結果（IC/FO イベント、同期後角速度）をグラフで表示します。
- **GUI:** Tkinter を用いたシンプルな GUI を提供し、特に同期パラメータ（`find_peaks`用）を対話的に調整できます。

### ファイル構成と説明

本ツールは以下の Python ファイルで構成されています。

1.  **`run_gait_analysis.py`**

    - **目的:** 解析パイプライン全体を実行するためのメインスクリプトであり、Tkinter ベースの GUI を提供します。
    - **主要クラス:** `GaitAnalysisApp`
    - **機能:** データ検索、初期信号表示、同期パラメータ調整用 GUI、各解析モジュール呼び出し、トライアル分割・抽出、結果統合・保存・表示。
    - **依存:** `tkinter`, `pandas`, `numpy`, `matplotlib`, `japanize-matplotlib`(推奨), `preprocessing.py`, `gait_cycles.py`, `pci.py`, `file_utils.py`, `temporal_parameters.py`, `kinematic_parameters.py`, `symmetry_indices.py`
    - **実行:** `python run_gait_analysis.py`

2.  **`preprocessing.py`**

    - **目的:** センサーデータの読み込み、前処理、および同期処理。
    - **主要関数:** `preprocess_angular_velocity`
    - **機能:** CSV 読込(ヘッダ skip, エンコード対応)、列名設定、不要列削除、左右信号抽出、左角速度符号反転、`find_peaks`によるピーク検出同期、ラグ適用アライメント。同期済み角速度 DataFrame 等を返す。
    - **依存:** `pandas`, `numpy`, `scipy.signal`, `pathlib`

3.  **`gait_cycles.py`**

    - **目的:** 同期済み角速度データからの歩行周期イベント(IC/FO)同定。
    - **主要関数:** `identify_gait_cycles`, `lowpass_filter`
    - **機能:** ローパスフィルタ適用、Swing 区間検出(閾値・持続時間)、IC/FO 候補(谷)検出(`find_peaks`)、イベント関連付け(Swing 後最初の IC 谷、IC+動的待機時間後の最も深い FO 谷)、IC/FO インデックス・時刻抽出。結果を辞書で返す。
    - **依存:** `pandas`, `numpy`, `scipy.signal`

4.  **`pci.py`**

    - **目的:** 位相協調指数(PCI)関連指標の計算。
    - **主要関数:** `calculate_pci`
    - **機能:** 定常歩行イベントデータに基づき、トライアルごとに基準脚を決定、全ストライドの位相(φ)を計算、全体データから φ の平均絶対誤差(φABS from 180)、変動係数(φCV)を計算し、PCI = φCV + 100\*(φABS/180) を算出。
    - **依存:** `pandas`, `numpy`

5.  **`file_utils.py`**

    - **目的:** ファイル操作関連のユーティリティ。
    - **主要関数:** `find_latest_csv_file`, `save_results`
    - **機能:** 最新 CSV 検索、DataFrame の CSV 保存(フォルダ自動作成、BOM 付き UTF-8)。
    - **依存:** `pandas`, `pathlib`, `os`

6.  **`temporal_parameters.py`**

    - **目的:** 時間関連歩行パラメータの計算。
    - **主要関数:** `calculate_temporal_params`
    - **機能:** ケイデンス、ストライド/立脚/遊脚時間の平均/SD/CV/割合を左右別に算出。
    - **依存:** `pandas`, `numpy`

7.  **`kinematic_parameters.py`**

    - **目的:** 運動学的歩行パラメータ（角速度ベース）の計算。
    - **主要関数:** `calculate_kinematic_params`
    - **機能:** 最大遊脚期角速度、ピーク立脚期角速度（谷）の平均/SD/CV を左右別に算出。
    - **依存:** `pandas`, `numpy`, `scipy.signal` (現在は未使用)

8.  **`symmetry_indices.py`**
    - **目的:** 左右対称性指数(SI)を計算する汎用関数。
    - **主要関数:** `calculate_symmetry_index`
    - **機能:** 左右のパラメータ値から SI = |L - R| / (0.5 _ (L + R)) _ 100% を計算。
    - **依存:** `numpy`, `pandas`

### 実行前の設定変更 (`run_gait_analysis.py`)

`run_gait_analysis.py` を実行する前に、スクリプトの**ファイル上部にある「解析実行のための設定」セクション**で、ご自身の環境に合わせて以下の設定を確認・変更してください。

1.  **入力データフォルダ (`DATA_FOLDER`)**:

    - **目的:** 解析したい CSV データファイルが**保存されているフォルダ**を指定します。
    - **デフォルト:** `DATA_FOLDER = Path("./")` (スクリプトと同じフォルダ)
    - **変更方法:** データがあるフォルダのパス（絶対パスまたは相対パス）に書き換えます。
    - **【重要】:** このパスが正しくないと、入力ファイルを見つけられません。

2.  **出力データフォルダ (`OUTPUT_FOLDER`)**:

    - **目的:** 解析結果の CSV ファイルを**保存するフォルダ**を指定します。
    - **デフォルト:** `OUTPUT_FOLDER = Path("./analysis_results")` (スクリプトと同じ階層に `analysis_results` フォルダを作成)
    - **変更方法:** 結果を保存したいフォルダのパスに書き換えます。存在しない場合は自動作成されます。

3.  **その他のパラメータ:**
    - 同セクションには、トライアル分割閾値 (`MAX_IC_INTERVAL_SEC`, `MIN_ICS_PER_TRIAL`)、定常歩行抽出の除外歩数 (`NUM_ICS_REMOVE_START`, `NUM_ICS_REMOVE_END`)、同期用 `find_peaks` のデフォルト値なども定義されており、必要に応じて調整可能です。

### 簡単な実行方法 (ターミナル不要)

ターミナルを直接開かずにダブルクリックで実行するためのランチャーを作成できます。

#### macOS (Automator アプリケーション)

1.  Automator を起動し、「アプリケーション」を選択。
2.  「シェルスクリプトを実行」アクションを追加。
3.  以下のスクリプトを貼り付け、**`PYTHON_EXEC` の行をご自身の Python パスに必ず修正**する。

    ```sh
    #!/bin/zsh
    SCRIPT_DIR=$(dirname "$0"); cd "$SCRIPT_DIR"
    # --- !!! 重要: Pythonパスの確認と修正 !!! ---
    PYTHON_EXEC="/Users/wanakahideyuki/miniforge3/bin/python" #<- ★★★各自のパスに要修正★★★
    SCRIPT_NAME="run_gait_analysis.py"
    osascript -e "tell application \"Terminal\" to do script \"cd '$SCRIPT_DIR' && '$PYTHON_EXEC' '$SCRIPT_NAME'; echo \\\"\\\\n>>> 解析終了。Enterで閉じる <<<\"; read\""; osascript -e "tell application \"Terminal\" to activate"
    ```

4.  「ファイル」>「保存」で、**Python スクリプトと同じフォルダ**に、ファイルフォーマット「**アプリケーション**」で保存（例: `歩行解析実行.app`）。
5.  保存した `.app` をダブルクリックして実行。

#### Windows (バッチファイル)

1.  Miniforge/Anaconda Prompt で `where python` を実行し、`python.exe` への**フルパス**を確認・コピー。
2.  メモ帳を開き、以下の内容を貼り付け、**`PYTHON_PATH` の行をご自身の Python パスに必ず修正**する（パスは `""` で囲む）。

    ```batch
    @echo off
    cd /d "%~dp0"
    REM --- !!! 重要: Pythonパスの確認と修正 !!! ---
    set PYTHON_PATH="C:\path\to\your\miniforge3\python.exe" & REM <- ★★★各自のパスに要修正★★★
    set SCRIPT_NAME="run_gait_analysis.py"
    echo %SCRIPT_NAME% を実行します...
    %PYTHON_PATH% %SCRIPT_NAME%
    echo. & echo >>> 解析が終了しました。何かキーを押すとウィンドウが閉じます。 <<< & pause > nul
    ```

3.  「ファイル」>「名前を付けて保存」で、「ファイルの種類」を「**すべてのファイル**」にし、「ファイル名」を「**実行.bat**」など `.bat` 拡張子で、**Python スクリプトと同じフォルダ**に保存。
4.  保存した `.bat` をダブルクリックして実行。

## これまでの作成のポイント・苦労した点

このツールの開発は、以下のステップと試行錯誤を経て進められました。

1.  **初期目標設定:** 左右の下腿 IMU データから、まずは時間同期を行い、最終的に PCI などの歩行パラメータを算出することを目標としました。
2.  **データ同期の試行錯誤:**
    - **相互相関:** 最初は一般的な相互相関を試みましたが、歩行の周期的なパターンが悪影響を与え、開始時の衝撃イベントでの同期が困難でした。
    - **限定相互相関:** 相関計算範囲をデータ先頭 1000 サンプルに限定しましたが、それでも期待通りの同期は得られませんでした。
    - **ピーク検出 (argmax):** 開始時の衝撃（加速度 Y 軸を同期信号として選択）の絶対値最大点を検出する方式に変更しました。しかし、データによっては開始直後に複数回の衝撃（意図しないもの含む）があり、左右で異なる衝撃の最大値を検出してしまい、同期がズレる問題が発生しました。
    - **ピーク検出 (find_peaks):** 複数ピークの問題に対処するため、`scipy.signal.find_peaks` を導入。高さ・突出度・距離のパラメータを指定して、よりロバストに最初の衝撃ピークを検出する方針としました。
    - **パラメータ調整の必要性:** `find_peaks` のパラメータはデータごとに最適値が異なるため、ユーザーが調整できるインターフェースが必要と判断しました。
3.  **GUI 導入とインタラクティブ調整:**
    - 同期パラメータ調整のため、Tkinter を用いた GUI を導入しました。
    - 初期信号を表示し、ユーザーがスライダーで `find_peaks` パラメータを調整し、その値で同期を実行するインタラクティブなワークフローを実装しました。
    - **苦労した点:**
      - GUI 表示直後にデータ読み込みやプロット処理を行うと、GUI が応答しなくなる（フリーズしたように見える）問題が発生しました。ステータス表示ラベルの導入、処理中のボタン無効化、`update_idletasks` の使用で対応しました。
      - macOS 環境で `matplotlib` と `tkinter` の連携時にセグメンテーションフォルトが発生する問題がありました。`matplotlib` のバックエンド変更や、よりシンプルなダイアログの使用を試み、最終的にグラフ埋め込み構造で安定化を図りました。
4.  **モジュール化:** コードの肥大化を防ぎ、管理しやすくするため、機能を複数のファイル (`preprocessing`, `gait_cycles`, `pci`, `file_utils` など) に分割しました。
5.  **歩行周期同定:**
    - ユーザー提示の文献（2 つ目）に基づき、Swing 区間検出 →IC 検出（Swing 後最初の谷）→FO 検出（IC 後＋動的待機時間後の最も深い谷）というアルゴリズムを実装しました。
    - Swing 検出閾値 (`swing_threshold`) が検出の成否に大きく影響し、初期値(200)では検出できず、調整(100)が必要でした。デバッグ用プロットの表示にも苦労しました（関数の戻り値の問題）。
    - FO 検出前の待機時間を、固定値ではなく「IC 時刻 - 直前 Swing Peak 時刻」で動的に計算するように改良しました。
6.  **データクレンジング（自動化）:**
    - 15m×2 往復という課題内容から、定常歩行区間のみを分析対象とするため、手動での範囲指定ではなく自動抽出を実装しました。
    - IC 間の時間差が閾値を超える箇所でトライアルを分割。
    - 各トライアルの IC 数が少ないものをノイズとして除去。
    - 各トライアルの開始 3 歩・終了 5 歩を除去。
7.  **パラメータ算出:**
    - ユーザー提示の文献に基づき、PCI（位相 CV + 正規化位相 ABS）を計算。
    - Stride Time CV（左右）を計算（当初 PCI 計算に含めていたが、後に時間パラメータとして分離）。
    - Max Swing Velocity, Peak Stance Velocity, Cadence, 各時間割合、対称性指数などの追加パラメータを実装。
    - **苦労した点:** PCI 計算で `num_strides_used_pci` が正しく更新されないバグがあり、初期化と代入箇所の修正が必要でした。
8.  **ファイル I/O と環境:**
    - CSV ファイルの読み込みで文字エンコーディングエラー (`UnicodeDecodeError`) が発生し、`cp932`/`shift_jis` の指定が必要でした。
    - CSV ファイルの列数が想定と異なり（25→29(誤認)→33）、列名リストの修正が必要でした。
    - 出力ファイルを指定フォルダにまとめる機能を追加しました。
    - ターミナルを開かずに実行するためのランチャー（Automator/バッチファイル）作成方法を提示し、特に Python 実行パスの指定の重要性を強調しました。
9.  **フォーマット問題:** 開発の過程で、複数ファイルにまたがるコードを提示する際に、インデントや改行が崩れてしまい、ユーザー側で `NameError` や `IndentationError` を引き起こすことが度々あり、コードの正確な伝達に苦労しました。最終的にファイルごとの出力で対応しました。

これらのステップを経て、現在のインタラクティブな同期調整と自動パラメータ算出を行うツールが形になりました。
